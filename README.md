# HikVision RTSP Tool

Μικρό εργαλείο (PyQt5) για ζωντανή προβολή RTSP από καταγραφικά Hikvision
(φτιαγμένο για το DS-7216HUHI-K2), μαζί με εργαλεία διάγνωσης.

[⬇ Download ](https://github.com/DProkos/HikVision-rtsp-tool/releases/latest/download/HikRTSPViewer.exe)

## Εγκατάσταση

```bash
pip install -r requirements.txt
```

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `hik_rtsp_viewer.py` | Προβολή καμερών σε πλέγμα 1/4/9/16, κύρια/δευτερεύουσα ροή, μονή προβολή με διπλό κλικ, στιγμιότυπα, λίστα RTSP URL. Δείχνει πάνω σε κάθε κάμερα κωδικοποίηση, ανάλυση και % σφαλμάτων. |
| `hik_diag.py` | Διαγνωστικό: στοιχεία συσκευής, ρυθμίσεις ροής, και δοκιμή μίας κάμερας με TCP / UDP / HTTP και διάφορα URL. Γράφει `diag_report.txt`. Δεν αλλάζει ρυθμίσεις. |
| `hik_stream_check.py` | Ελέγχει αν η ροή είναι κρυπτογραφημένη: στιγμιότυπο από το καταγραφικό, ανάλυση κεφαλίδων H.264 και πειραματικές δοκιμές αποκρυπτογράφησης AES-128/256 με τον κωδικό επαλήθευσης ή κλειδί που δίνεις (1008 συνδυασμοί). Γράφει `stream_check.txt`. |
| `hik_encryption.py` | Ψάχνει στο ISAPI του καταγραφικού ρύθμιση κρυπτογράφησης ροής (Hik-Connect) και, μόνο αν το επιβεβαιώσεις, την απενεργοποιεί. Κρατά αντίγραφο ασφαλείας. |

## Χρήση

```bash
python hik_rtsp_viewer.py
```

Συμπλήρωσε IP, χρήστη και κωδικό του καταγραφικού και πάτα **Προβολή**.

Μορφή RTSP Hikvision:
`rtsp://USER:PASS@IP:554/Streaming/Channels/<κανάλι><01|02>`
(01 = κύρια ροή, 02 = δευτερεύουσα). Οι IP κάμερες (D1, D2, …) αριθμούνται
από την τιμή «IP βάση» + 1 (συνήθως 16 ή 32).

## HTTPS (κρυπτογραφημένη σύνδεση με το καταγραφικό)

Στη «Ροή: Στιγμιότυπα HTTP» τσέκαρε **HTTPS** (η θύρα γίνεται αυτόματα 443). Πρέπει να
είναι ενεργό και στο καταγραφικό (Δίκτυο → Υπηρεσία δικτύου, ή Προηγμένες, ανάλογα με το
firmware). Η θύρα HTTPS ορίζεται στο Δίκτυο → Θύρα.

- Τα καταγραφικά έχουν **αυτο-υπογεγραμμένο** πιστοποιητικό, οπότε δεν γίνεται κλασικός
  έλεγχος. Το πρόγραμμα **απομνημονεύει το πιστοποιητικό στην πρώτη σύνδεση**
  και αν αργότερα αλλάξει, **σταματά** με προειδοποίηση «⚠ ΑΛΛΑΞΕ το πιστοποιητικό HTTPS»
  (θα μπορούσε να είναι άλλο, πλαστό, καταγραφικό).
- Αν το άλλαξες εσύ (π.χ. νέο firmware), πάτα **«🔓 Επαναφορά πιστοποιητικού»**.
- **Δεν δουλεύει;** Τρέξε `python hik_https_check.py` (βρίσκεται στο `docs/https/`): δοκιμάζει ένα-ένα τα στάδια (θύρα,
  TLS με διάφορες εκδόσεις, πιστοποιητικό, αίτημα) και λέει πού αποτυγχάνει. Στο κελί της
  κάμερας φαίνεται και ο λόγος, π.χ. «Η θύρα 443 είναι κλειστή».
- Η πρώτη σύνδεση εμπιστεύεται ό,τι δει· κάν' την από το τοπικό σου δίκτυο.
- Για παλιά firmware επιτρέπεται TLS 1.0+ και ασθενή πιστοποιητικά (RSA 1024/SHA1).
- Δεν υποστηρίζεται MJPEG μέσω HTTPS (το καταγραφικό που δοκιμάσαμε δεν έχει MJPEG).
- Για πρόσβαση από το internet προτιμήστε **VPN** προς το τοπικό δίκτυο αντί να ανοίξετε θύρα.

## Δημιουργία .exe (Windows)

Όλα βρίσκονται στον φάκελο [`packaging/`](packaging/):

| Αρχείο | Τι κάνει |
|---|---|
| `build_exe.bat` | Διπλό κλικ: εγκαθιστά τις απαιτήσεις και φτιάχνει το exe |
| `build_exe.py` | Το ίδιο από γραμμή εντολών (`python packaging/build_exe.py`) |
| `make_logo.py` | Ξαναφτιάχνει το λογότυπο και το εικονίδιο (`assets/logo.png`, `assets/icon.ico`) |

```bash
pip install -r requirements.txt
python packaging/build_exe.py            # ένα αρχείο: packaging/dist/HikRTSPViewer.exe
python packaging/build_exe.py --onedir   # φάκελος (ξεκινά πιο γρήγορα)
python packaging/build_exe.py --console  # με κονσόλα, για να βλέπεις σφάλματα
```

- Το PyInstaller **δεν κάνει cross-compile**: για `.exe` τρέξε το στα Windows.
- Οι ρυθμίσεις (`hik_viewer_config.json`), τα στιγμιότυπα και το `discover_debug.txt`
  αποθηκεύονται **δίπλα στο exe**.
- Γρήγορος έλεγχος του exe: `HikRTSPViewer.exe --selftest` (με `--console` build).

## Πλήρης οθόνη και προσαρμογή στο μέγεθος

- **F11** (ή «⛶ Πλήρης οθόνη»): το πρόγραμμα γεμίζει όλη την οθόνη. Μένουν όλα τα
  στοιχεία και προσαρμόζονται: η εικόνα μεγαλώνει ώστε να γεμίζει κάθε κελί, τα
  γράμματα και τα κουμπιά μεγαλώνουν με το μέγεθος του παραθύρου, και η μπάρα
  σπάει σε πολλές γραμμές όταν δεν χωράει (δεν κόβεται τίποτα).
- **F10** (ή «▣ Μόνο εικόνα»): κρύβει μπάρα, λίστα και μπάρα κατάστασης, μένουν μόνο
  οι κάμερες. **Esc** επιστρέφει (και ξανά Esc βγαίνει από το full screen).
- **PageUp / PageDown**: προηγούμενη / επόμενη κάμερα ή σελίδα.
- Σε μεγάλη οθόνη η μικρή ανάλυση (352×288) φαίνεται θολή όταν μεγαλώνει· στο
  «Ανάλ.» διάλεξε «Πλήρης» (λιγότερα fps).

## Εύρεση καμερών από το καταγραφικό

Το κουμπί **«🔍 Εύρεση καμερών από το καταγραφικό»** (κάτω από τη λίστα καμερών)
ρωτά το καταγραφικό μέσω ISAPI (θύρα HTTP) ποιες κάμερες έχει: ονόματα αναλογικών
καναλιών, IP κάμερες με τη διεύθυνσή τους, αν είναι online, και τους πραγματικούς
αριθμούς καναλιών. Φτιάχνει τη λίστα μόνο του και την αποθηκεύει για την επόμενη
φορά. Οι IP κάμερες που είναι εκτός σημειώνονται με ⚠. Δεν αλλάζει τίποτα στη
συσκευή. Αν το firmware δεν δίνει τα δεδομένα, γράφει `discover_debug.txt` (χωρίς
κωδικούς) με τις απαντήσεις του καταγραφικού, για διάγνωση.

## Στιγμιότυπα HTTP (όταν η ροή RTSP είναι κρυπτογραφημένη)

Αν το `hik_stream_check.py` δείξει ότι η ροή RTSP είναι κρυπτογραφημένη και δεν
μπορείς να την απενεργοποιήσεις, στο viewer διάλεξε **Ροή: Στιγμιότυπα HTTP**.
Αντί για RTSP, το πρόγραμμα παίρνει την εικόνα μέσω HTTP (δεν κρυπτογραφείται): δοκιμάζει
πρώτα ζωντανή ροή MJPEG (`httpPreview`, ~8-10 fps) και, αν δεν υποστηρίζεται,
γρήγορα στιγμιότυπα (`/ISAPI/Streaming/channels/N01/picture`) με ρυθμό που
ορίζεις στο πεδίο **fps**. Συμπλήρωσε και τη θύρα **HTTP** (συνήθως 80).
Αναλυτικά στο [ΟΔΗΓΟΣ_ΕΙΚΟΝΑΣ.md](ΟΔΗΓΟΣ_ΕΙΚΟΝΑΣ.md).

## Πράσινη / χαλασμένη εικόνα

Αν η εικόνα βγαίνει πράσινη και το `hik_diag.py` δείχνει ~0 καθαρά καρέ με
όλους τους τρόπους μεταφοράς, η ροή είναι πιθανότατα κρυπτογραφημένη από το
Hik-Connect («Κρυπτογράφηση βίντεο και εικόνας»). Απενεργοποίηση:

- εφαρμογή Hik-Connect (κύριος λογαριασμός της συσκευής) → Ρυθμίσεις συσκευής,
- μενού του καταγραφικού: Configuration → Network → Platform Access,
- iVMS-4200: Remote Configuration → Network → Hik-Connect,
- ή `python hik_encryption.py`, αν το firmware τη δίνει μέσω ISAPI.

## Σημείωση ασφαλείας

Οι ρυθμίσεις (μαζί με τον κωδικό) αποθηκεύονται τοπικά σε απλό κείμενο στο
`hik_viewer_config.json`, που εξαιρείται από το git μέσω `.gitignore`.
